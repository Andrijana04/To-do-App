This is a simple To-Do application built using **HTML, CSS, and JavaScript**.

---

## Features
- Add new tasks
- Mark tasks as done
- Delete tasks
- Save tasks in localStorage (data persists after refresh)

---

## Technologies Used
- HTML
- CSS
- JavaScript (DOM manipulation)
- LocalStorage API

---

## How it works
- Tasks are stored as objects in an array
- Data is saved in localStorage using JSON
- The UI is re-rendered after every change
